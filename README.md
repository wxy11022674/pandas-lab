# Pandas Lab · 数据可视化工作台

面向可视化导论课程的双语 pandas 数据处理与分析项目。导入 CSV、Excel 或 JSON，通过数据表、字段分布、关联图表和拖拽编辑器执行真实 pandas 分析。打开即可使用已准备好的数据，提供五步完整演示。

## GitHub Pages 在线版

静态在线版通过 Pyodide / WebAssembly 在浏览器中运行真实 pandas，不需要 Render 或 Python 服务器。网页、Python 计算组件和示例文件均由 GitHub Pages 提供。用户导入的数据在浏览器内处理，并保存于当前站点的 IndexedDB。

首次打开需要下载计算组件；之后浏览器通常会缓存这些文件。清除浏览器站点数据会删除保存的工作区，重要结果请及时导出。该版本不提供账户登录或跨设备同步，处理能力取决于设备内存。

```sh
npm ci
npm run build:pages
npm run test:browser-engine
```

构建产物为 `dist/`。仓库的 `Deploy GitHub Pages` 工作流先验证 WebAssembly 引擎，再发布静态文件。操作逻辑与本地 Python 后端共用 `backend/` 源码，浏览器适配层只负责请求、上传和下载转换。设置步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

## 本地启动

以下是保留的本地服务器运行方式，需要 Python 3.11+、Node.js 22.12+。GitHub Pages 在线版无需安装 Python。

Windows 双击 **启动工作台.cmd**，或者在项目目录运行：

```powershell
.\start.ps1
```

脚本安装 Python 依赖、安装并构建前端，然后启动服务。在浏览器打开 **http://127.0.0.1:8000** 。关闭服务使用 Ctrl+C。

已安装依赖时可使用 `./start.ps1 -SkipInstall`。构建后的前端由 FastAPI 一并提供服务，无需同时启动两个进程。

## 页面使用流程

主导航按任务分成四步，可自由切换：**选数据 → 整理数据 → 分析与画图 → 导出结果**。

- 选数据：首页提供上传文件、打开现成示例、继续已载入表格三条路径。
- 整理数据：先查看表格，再选择筛选、清洗、计算或合并。组合筛选确认后直接显示结果和记录数变化；其他处理操作先预览再应用。
- 分析与画图：宽屏下左侧设置字段、右侧显示图表；修改设置默认自动更新，图表下方查看联动明细。窄屏下上下排列。
- 导出结果：统一提供结果表格、图表页入口、处理代码和操作记录下载。

数据选择集中在当前表格下拉框；点击列名才展开列详情。原有数据版本、导入文件及操作历史继续保留。界面代码为 `src/Workbench.tsx` 和 `src/Workflow.tsx`，流程样式为 `src/workflow.css`。

界面已完成本地浏览器检查，包括自动生成图表、图表联动筛选、缺失值统计说明和语言切换。

## 现成数据与演示

打开网站先进入选择数据页：可以上传自己的表格，或点击 **打开示例，开始分析** 使用已处理的 96 行校园能耗表。顶部 **现成数据** 中提供五张表及完整下载：

| 文件 | 记录 | 用途 |
| --- | ---: | --- |
| reference | 96 | 已去重、填补、关联和计算，可以直接分析 |
| energy_2025 | 99 | 原始练习：3 条重复记录、15 个空值、1 条待检查高值 |
| buildings | 8 | 唯一楼宇编号、名称、类型、校区、面积、使用人数 |
| energy_2026 | 96 | 同结构的第二年度数据，练习追加与时间汇总 |
| monthly | 12 | 整理版按月汇总结果，供核对 |

全部是固定随机种子生成的**教学模拟数据**，包括 2026 全年数据，不是真实观测。待检查高值保留在参考结果中；中位数填补用于演示，不代表适用于所有真实数据。

数据位于 `examples/campus/`：每张表同时提供 CSV、JSON，`campus-data.xlsx` 包含全部表及说明，`campus-data.zip` 包含完整材料。Excel 中两个能耗强度字段使用公式，其他字段为参考结果。字段名与原始类别值跨语言保持不变，界面提供双语字段说明。

点击 **现成数据 → 开始完整演示**，按顺序点击“执行这一步”：

1. 去重：99 行变为 96 行。
2. 填补四个数值列的空值、整理电表状态文本。
3. 通过楼宇编号关联楼宇信息。
4. 计算单位面积能耗与人均能耗。
5. 生成楼宇能耗图；点击柱子定位该楼宇的 12 条记录。

完整结果与 reference 逐项一致，用电量合计为 3,365,213.34 kWh。也可以直接打开整理版，选择“图表分析”，选字段并生成图表。

## 功能与计算边界

- 导入 CSV（UTF-8 / GB18030）、Excel `.xlsx`（选择工作表）、JSON 对象数组。
- 数据表分页、全表搜索、组合条件筛选、多列排序、重命名、删除列、类型转换。
- 去重、缺失值删除/常数/均值/中位数填补、文本整理与拆分、数值截断。
- 计算列、日期提取、时间重采样、多字段多指标聚合、拖字段构建透视表、宽表转长表。
- 多表连接及键匹配检查、同结构表追加；连接校验防止意外多对多膨胀。
- 字段分布、缺失条、IQR 潜在异常值、描述统计、相关性热力图；点击相关性格子进入散点图。
- 柱状、折线、面积、散点、直方、箱线图；点击柱子或框选散点/直方图区间筛选明细。
- Graphic Walker 拖拽探索；基础筛选、聚合、排序由本地 pandas 查询适配器执行。未支持的表达式明确报错，不执行任意 SQL 或 Python。
- 预览和应用分开，每个处理步骤保存不可变版本，可撤销并打开历史；缺失值删除与填补方案对比。
- CSV、原始 CSV、可复现 Python 脚本、PNG 图表、JSON 图表配置导出。图表配置可在本机保存并重新打开。
- 中文/英文切换保留同一份数据和操作状态；用户导入的字段与值不自动翻译。

数据与处理步骤位于 `data/`，已加入 `.gitignore`。浏览器保存当前版本与图表配置。前端以 `src/Workbench.tsx` 为入口，后端为 `backend/main.py`、`advanced.py`、`extended_api.py`。早期 App 文件保留但不再是页面入口。

上传上限 10 MB、50,000 行、100 列。散点图超过 3,000 条时采样并显示提示；描述统计基于当前完整版本。箱线图须线表示最小/最大值，页面有说明。分组和连接产生新记录，无法宣称聚合前后存在逐行对应关系。

## 验收

自动测试覆盖示例包数量与缺失情况、完整处理结果、脚本复现、透视/聚合/时间汇总、关联校验、JSON/Excel 导入、图表筛选边界、大量分类绘图、拖拽编辑器查询、非法表达式拒绝和线上浏览器会话隔离。当前 28 项通过。

浏览器验收覆盖五步演示、柱状图联动明细、透视预览、拖拽探索实际计算以及语言切换。前端通过 TypeScript 检查和生产构建。

这是课程演示项目；尚未实现账户、多人协作、数据库连接或任意 pandas 方法。Docker 部署默认启用浏览器会话隔离，各访客只访问自己会话内的数据。线上临时文件的生命周期见部署说明。第三方依赖应定期通过 `npm audit` 检查；依赖审计不等于完整安全审计。
