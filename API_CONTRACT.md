# Pandas Lab API contract

Local FastAPI at 127.0.0.1:8000, frontend proxy /api. All JSON serializable, null for missing/nonfinite. Errors {detail:{code:string,params:object}}; UI translates codes. ISO dates. Preserve raw field names. Reserved internal row key `_row_id`, excluded from all business operations/exports; reject uploads containing that field with RESERVED_COLUMN. CSV <=10MB, <=50000 rows and <=100 columns. No arbitrary code execution.

## Types

`Operation = {type: 'filter'|'sort'|'convert'|'deduplicate'|'fill_missing'|'groupby', params: object}`

- filter: {column, operator: 'eq'|'ne'|'gt'|'gte'|'lt'|'lte'|'contains'|'is_null'|'not_null', value?: string|number}
- sort: {column, ascending:boolean}
- convert: {column, target:'numeric'|'date'|'string', errors:'raise'|'coerce'}
- deduplicate: {columns:string[]} (empty means all business columns)
- fill_missing: {column, method:'drop'|'constant'|'mean'|'median', value?:string|number}
- groupby: {column:string, value_column:string, aggregate:'sum'|'mean'|'median'|'count'|'min'|'max'}; result retains grouping column and value column, new internal row IDs; provenance no longer row-level after aggregate.

`Column = {name:string,dtype:string,kind:'numeric'|'date'|'string',missing:number,unique:number,stats:null|{min:number|null,max:number|null,mean:number|null,median:number|null}}`

`HistoryStep = {id:string,parent_id:string|null,operation:Operation|null,rows:number,affected_rows:number}`

`Version = {id:string,dataset_id:string,dataset_name:string,original_version_id:string,parent_id:string|null,operation:Operation|null,rows:number,columns:Column[],preview:Record<string,unknown>[],page:number,page_size:number,total_preview_rows:number,total_missing:number,duplicates:number,affected_rows:number,changed_ids:number[],removed_ids:number[],history:HistoryStep[],code:string}`

`Dataset = {id:string,name:string,original_version_id:string,latest_version_id:string}`

## Endpoints

- GET /api/health -> {status:'ok',pandas_version:string}
- GET /api/datasets -> Dataset[]
- POST /api/demo -> Version (creates deterministic 12-month campus energy demo with Chinese column names, numeric columns including `用电量`, `面积`, `人数`, `月份` as YYYY-MM string, `楼宇` categorical, deliberate missing + duplicates; first column name `楼宇`).
- POST /api/upload multipart file, encoding form default 'utf-8-sig', name from filename -> Version
- GET /api/versions/{id}?page=1&page_size=20&affected_only=false -> Version (affected_only filters changed + removed against parent data, removed rows retained for inspection; total_preview_rows is filtered count)
- POST /api/versions/{id}/preview body Operation -> Version with id 'preview' (no persistence)
- POST /api/versions/{id}/operations body Operation -> Version (immutable new child)
- POST /api/compare body {version_id:string,column:string,group_by:string|null,aggregate:'sum'|'mean'|'median'|'count',a:Operation,b:Operation} -> Comparison
- POST /api/versions/{id}/chart body {type:'bar'|'line'|'scatter'|'histogram',x:string,y:string|null,aggregate:'sum'|'mean'|'median'|'count',bins:number} -> {type:string,x_label:string,y_label:string,labels:string[],series:{name:string,data:(number|null)[]}[],points:number[][],sampled:boolean,total_points:number}
- GET /api/versions/{id}/export.csv -> UTF8 BOM CSV without _row_id
- GET /api/versions/{id}/export.py -> standalone reproducible Python, reads original.csv using same import configuration; demo script embeds original data. Generated by same operation specs. No frontend execution.
- GET /api/versions/{id}/recipe.json -> {schema_version:1,dataset_name:string,operations:Operation[]} (include import parameters if applicable)
- GET /api/versions/{id}/original.csv -> original business data for reproducibility

`Comparison = {base:Version,a:Version,b:Version,column:string,distribution:{labels:string[],base:number[],a:number[],b:number[]},groups:{labels:string[],base:(number|null)[],a:(number|null)[],b:(number|null)[]},summary:{base:Metrics,a:Metrics,b:Metrics}}`

`Metrics = {rows:number,non_null:number,missing:number,retention:number,mean:number|null,median:number|null,sum:number|null}`

Compare creates persistent a/b child versions of same immutable base so users may adopt either; distribution uses common bins across union, normalized percentages excluding nulls and explicitly shows non_null. Groups aligned by category across union, absent groups null. sum all missing yields null. Numeric target required; finite stats only. Data page/code/history/undo all tied to version ID. Mean/median all-null raises ALL_MISSING. For chart count groupby.count counts nonmissing y if y provided else group sizes. Known errors include NOT_FOUND, EMPTY_FILE, FILE_TOO_LARGE, TOO_MANY_ROWS, TOO_MANY_COLUMNS, INVALID_CSV, ENCODING_ERROR, RESERVED_COLUMN, INVALID_COLUMN, INVALID_OPERATION, INVALID_VALUE, NUMERIC_REQUIRED, ALL_MISSING, CONVERSION_FAILED, INVALID_AGGREGATE.


## Workbench v2 additions

`GET /api/workspace/bootstrap` creates the five versioned synthetic example tables once, returns datasets, example original version IDs, default reference version and bilingual field metadata.

`POST /api/upload` accepts CSV, XLSX (form field `sheet`) and JSON arrays. `POST /api/upload/sheets` inspects workbook sheet names. The same size/shape limits apply. `GET /api/examples/download/{filename}` serves explicitly allowlisted example files.

Additional operation types (same preview/apply contract): rename, drop_columns, calculate, text, date_extract, filter_multi, sort_multi, aggregate, pivot, melt, merge, concat, resample, clip. Parameter validation and executable transformations are defined in `backend/advanced.py`. Join dependencies are embedded in exported Python scripts; source data still comes from the exported original.csv.

Version endpoints:
- `POST /query`: conditions, logic, search, page, page_size, sort, ascending; temporary full-data filtering, returns rows and total.
- `GET /profile?column=…`: nulls, distinct values, distribution, numeric statistics and IQR boundaries.
- `GET /statistics`: numeric describe and pairwise correlations including sample counts.
- `POST /visual`: type, x, y, color, aggregate, bins; pandas aggregates and chart-ready payload, histogram edges for exact linkage.
- `POST /join-info`: right_version, left_on, right_on; matches, null keys and duplicate key counts.
- `POST /walker`: Graphic Walker structured workflow; allowlisted filter/transform/view/sort queries. Unsupported queries return 400 UNSUPPORTED_QUERY. Regex support is deliberately limited to literals, anchors and up to two .* wildcards; richer syntax is rejected. No arbitrary code/SQL execution.

Default reference is 96 rows × 14 columns; raw 2025 is 99 rows × 7 columns with 15 missing cells and 3 duplicates. Reference electricity sum is 3365213.34. All example observations are synthetic, including the 2026 records.
